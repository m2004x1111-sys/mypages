## 一篇笔记，可以从一个问题开始

这是学习笔记的示例页面。与其一次整理所有知识，不如先写清楚今天遇到的一个问题。

### 问题是什么

用自己的话描述它，留下当时的思考。

### 我试过什么

记录尝试过的方法、得到的结果，以及还没理解的部分。

### 下次怎么做

用一两句话收尾，给未来的自己留一个提示。

## 给笔记一个简单的结构

| 部分 | 可以写什么 |
| --- | --- |
| 问题 | 为什么会遇到它 |
| 过程 | 尝试、例子、观察 |
| 收获 | 这次理解了什么 |
| 待办 | 下一步还想了解什么 |

有时候，写清楚问题本身，就是进步。
